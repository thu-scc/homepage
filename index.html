Cross-disciplinary Collaboration

交叉合作

我们相信，超算技术的价值不止于竞赛场——当它与真实的科学问题结合，才能产生最大的影响力。

GRID × THUSCC · AI Agent

伽马射线暴自动搜索 Agent

基于大语言模型的智能体，将数据拉取、搜暴算法执行、候选体校验、GCN 通告发布整合为全流程自动化管线，将 GRB 从发现到可发布的周期缩短至一小时以内。

GRID × THUSCC · HPC

卫星数据 Pipeline 重构与优化

对天格前 Pipeline 数据处理软件进行软件工程重构和性能优化，提升卫星遥测数据预处理的吞吐量和可维护性。

GRID × THUSCC · 分布式

太空天基算力分布式系统设计

为未来大规模卫星星座设计星上/地面协同的分布式计算架构，探索在资源受限的星载环境中进行实时数据处理的可行方案。

化工系 LEB × THUSCC

DNA 聚合酶 θ 亚基挖掘

超算队提供 HPC 计算支撑与序列分析加速方案，协助从大规模基因组数据库中挖掘 DNA 聚合酶 θ 亚基。

Join Us

加入我们

我们在寻找对高性能计算、系统优化、并行编程有热情的同学。

我们在寻找

  • 对高性能计算、系统优化、并行编程有兴趣
  • 有扎实的编程基础（C/C++/CUDA/Python 等）
  • 善于学习新技术，不怕啃硬骨头
  • 有团队合作精神

不需要

  • 不要求有超算经验——我们会从零培训
  • 不限院系——计算机、物理、数学、化工、天文均可
  • 不限年级——大一到研究生均欢迎

如何加入

每年秋季学期招新，关注清华大学学生超算团队公众号或直接联系指导老师。
即使不在招新季，如果你对超算交叉合作感兴趣，也欢迎随时联系。
